# Курсовая работа №2
____
## Тема 
В этой работе реализована программа, которая собирает данные о самолетах в воздушном пространстве той страны, которую вы выберете.
____
## Реализация
 - Создание классов для работы с API. 
 - Создание класса для работы с информацией о самолетах.
 - Создание классов для работы с файлами.
 - Создание функции для взаимодействия с пользователем.
____
## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/Sergey-Shinkevich/Country_Airplanes.git] (https://github.com/Sergey-Shinkevich/Country_Airplanes.git)
2. Установите зависимости через Poetry:
   ```bash
   poetry install
3. Для запуска тестов и генерации отчета о покрытии:
   ```bash
   pytest --cov=src
____
## Использованные API сервисы
- Для получения координат стран: Open Street Map https://nominatim.openstreetmap.org/
- Для получения данных о воздушных судах: Open Sky Network https://opensky.network.org/ 
____
## Ограничения
Обработка антимеридиана: текущая реализация не поддерживает ограничивающие рамки (bounding boxes), пересекающие 180-й меридиан (антимеридиан). Запросы, охватывающие области, разделенные этой линией, могут приводить к ошибкам API. Учитывая масштаб проекта, данная функциональность исключена из текущей версии.
