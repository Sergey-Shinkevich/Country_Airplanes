Ограничения
Обработка антимеридиана: текущая реализация не поддерживает ограничивающие рамки (bounding boxes), пересекающие 180-й меридиан (антимеридиан). Запросы, охватывающие области, разделенные этой линией, могут приводить к ошибкам API. Учитывая масштаб проекта, данная функциональность исключена из текущей версии.
